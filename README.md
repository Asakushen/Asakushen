## 正在做什么 ✦

- **炼化链接与信息**：构建 [浅草玉简 / Chill Jade](https://github.com/Asakushen/chill-jade)，一个以隐私与自托管为先的个人书签花园。
- **把网络状态说人话**：打磨 [NetScope · IP 出口雷达](https://ip.chillg.de)，为 Clash / Meta / Sing-box 的分流排查提供一眼看懂的出口诊断。
- **持续折腾**：AI 工作流、自托管服务、Cloudflare 边缘能力，以及那些能让日常工具更顺一点的小细节。
